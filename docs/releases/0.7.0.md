# rutis 0.7.0

[English](0.7.0.en.md) · [迁移指南](../migration-interop-to-0.7.md)

0.7.0 是发布列车的首次发布：插件控制面、多语言插件、远程运行时与节点互联整合为一套可直接使用的开发流程。`rutis-host` 让 TypeScript、JavaScript 和 Python 插件从创建项目到运行、检查和开发重载都不需要编写 Rust 宿主。

## 发布包

以下包版本均为 **0.7.0**，基于内核 `rutis` 0.6.1：

| 注册表 | 包 |
| --- | --- |
| crates.io | `rutis-bridge`、`rutis-loader`、`rutis-host` |
| npm | `@arcships/rutis`、`@arcships/rutis-runtime`、`@arcships/rutis-host`，以及四个平台的 host 包 |
| PyPI | `rutis`、`rutis-host` |
| GitHub | Linux / macOS，x64 / arm64 的 `rutis-host` 二进制与 SHA-256 校验文件 |

内核 `rutis` 不在本次发布中，仍为 0.6.1。`rutis-cli`、agent 示例、`aimux-llm` 和 dylib 工具链继续使用各自版本。

## 内容

- **插件控制面**：`rutis-loader` 提供分层配置、动态增删改、持久化、服务目录、表达式和多种插件来源；支持 volatile 配置及插件自行卸载。
- **多语言插件**：JS/TS 与 Python 叶子插件、命名运行时、服务导入导出、生命周期清理、跨会话引用转发和模块刷新。
- **远程运行时**：可在其他机器的语言运行时中运行 loader 行，提供控制租约、释放和接管机制。
- **节点互联**：连接共享、服务导入导出、插件托管、事件转发、多跳调用及断线重连。
- **传输**：本地 Unix socket、继承 socket、内存通道、WebSocket，含 TLS、认证和共享监听器。
- **通用宿主**：`rutis-host new`、`check`、`run`、`dev`，以及匹配版本的 Node / Python 插件脚手架。
- **开发文档与验证**：中英文角色指南，通道、会话、运行时和节点一致性测试，重连与进程生命周期压力测试。

## 兼容

`rutis-interop` 合并进 `rutis-bridge`，旧包不再更新；npm 插件 SDK 与运行时拆分为 `@arcships/rutis` 和 `@arcships/rutis-runtime`。旧包用户需要迁移依赖、导入路径、feature 和生成绑定，详见[迁移指南](../migration-interop-to-0.7.md)。宿主与语言运行时应使用同一列车版本。

包版本不等于协议版本：本地会话使用协议 2，带 endpoint 身份的会话使用协议 3。

`rutis-host` 和本地语言运行时支持 Linux / macOS；Windows 用户使用 WSL。Node 要求 24+，Python 要求 3.12+。

## 开始使用

```bash
npx @arcships/rutis-host@0.7.0 new greeter --lang node
uvx --from rutis-host==0.7.0 rutis-host new greeter-py --lang python
```
