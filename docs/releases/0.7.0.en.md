# rutis 0.7.0

[中文](https://github.com/arcships/rutis/blob/v0.7.0/docs/releases/0.7.0.md) · [Migration guide](https://github.com/arcships/rutis/blob/v0.7.0/docs/migration-interop-to-0.7.en.md)

0.7.0 is the first release of the release train: the plugin control plane, language runtimes and networked nodes in one developer workflow. With `rutis-host`, TypeScript, JavaScript and Python authors can scaffold, check, run and reload plugins without writing a Rust host.

## Packages

These packages are versioned **0.7.0** and build on the `rutis` core 0.6.1:

| Registry | Packages |
| --- | --- |
| crates.io | `rutis-bridge`, `rutis-loader`, `rutis-host` |
| npm | `@arcships/rutis`, `@arcships/rutis-runtime`, `@arcships/rutis-host`, and four platform host packages |
| PyPI | `rutis`, `rutis-host` |
| GitHub | `rutis-host` binaries and SHA-256 checksums for Linux/macOS, x64/arm64 |

The `rutis` core is not part of this release and stays at 0.6.1. `rutis-cli`, the agent examples, `aimux-llm` and dylib tools keep their own versions.

## What's in it

- **Plugin control plane:** layered configuration, dynamic edits, persistence, service catalogs, expressions, multiple plugin sources, volatile configuration and self-disposal through `rutis-loader`.
- **Language plugins:** JS/TS and Python leaf plugins, named runtimes, service sharing, lifecycle cleanup, cross-session references and module refresh.
- **Remote runtimes:** loader rows on other machines, controller leases, release and takeover.
- **Nodes:** shared connections, service imports/exports, hosted plugins, events, multi-hop calls and reconnection.
- **Transports:** local and inherited Unix sockets, in-memory channels, WebSocket with TLS, authentication and shared listeners.
- **Standalone host:** `rutis-host new`, `check`, `run` and `dev`, with matching Node/Python project templates.
- **Guides and validation:** Chinese/English role-based guides, channel/session/runtime/node conformance suites, and reconnect/process-lifecycle soak tests.

## Compatibility

`rutis-interop` is folded into `rutis-bridge` and the old packages have been withdrawn. The npm SDK and runtime are now `@arcships/rutis` and `@arcships/rutis-runtime`. Users of the old packages must migrate dependencies, imports, features and generated bindings using the [migration guide](https://github.com/arcships/rutis/blob/v0.7.0/docs/migration-interop-to-0.7.en.md). Hosts and language runtimes should come from the same train version.

Package versions are separate from protocol versions: local sessions use protocol 2; endpoint sessions use protocol 3.

`rutis-host` and local language runtimes support Linux/macOS; use WSL on Windows. Node 24+ and Python 3.12+ are required.

## Getting started

```bash
npx @arcships/rutis-host@0.7.0 new greeter --lang node
uvx --from rutis-host==0.7.0 rutis-host new greeter-py --lang python
```

Read the [developer guides](https://github.com/arcships/rutis/blob/v0.7.0/docs/guide/README.en.md) for plugins, embedding and networking.
